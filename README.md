# Linux Storage Optimizer

## About the Project

Linux Storage Optimizer is a mini-project assigned to our team during our internship at **Ericsson**. The main purpose of this project is to help us learn new technologies, improve our problem-solving skills, and gain practical experience by working on a real-world use case.

The idea behind the project is to monitor the storage of a Linux system and identify situations where disk usage becomes critically high. Instead of continuously running an AI model, the system follows an event-driven approach, where AI is triggered only after a predefined storage threshold is reached. Based on the analysis, the system can recommend or perform safe cleanup operations to free up disk space.

This repository contains our implementation, experiments, documentation, and progress throughout the internship.
